# ALS Computing public GitHub site

The ALS is the (Advanced Light Source)[https://als.lbl.gov] at (LBNL)[https://www.lbl.gov].  This is the GitHub site for (the Computing Group)[https://als.lbl.gov/computing-site/] within the ALS.

Here you'll find public documentation for the applications and services that ALS Computing has made available.

Some of these are useful for everyone, some are only useful for scientists at the ALS.
